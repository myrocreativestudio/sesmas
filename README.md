Portal rasmi berestetika tinggi dan interaktif bagi **Sekolah Kebangsaan Sungai Mas (JHEOA), Kuantan, Pahang Darul Makmur** (Kod Sekolah: `CBBA091`). Laman web ini dibina menggunakan **Vanilla HTML5, Modern CSS3 (Glassmorphism & Aurora Glow Mesh), dan JavaScript ES6+** yang sangat pantas, lancar dan responsif pada semua peranti.

---

## 🌟 Ciri-Ciri Utama

- **Ultra-Modern Frosted Glassmorphism:** Efek panel kaca berkabut (`backdrop-filter: blur(18px) saturate(180%)`), bayang-bayang bertingkat, dan sempadan bercahaya lembut.
- **Dynamic Aurora Mesh Background:** Animasi pergerakan orbs kecerunan organik di latar belakang (Emerald, Royal Gold & Cyan).
- **Dark & Light Mode Switcher:** Pensuisan tema gelap & terang dengan simpanan tetapan pengguna (`localStorage`).
- **Pintasan Carian Pintar (Smart Search Modal):** Tekan butang carian atau kekunci pantas `Ctrl + K` / `Cmd + K` untuk carian segera berindeks.
- **Maklum Balas Audio Mikro (Web Audio API):** Kesan bunyi interaktif lembut ketika menukar tab atau mengklik butang dengan pilihan mod senyap (*mute*).
- **Galeri Gambar & Lightbox Skrin Penuh:** Penapis kategori aktiviti segera dan paparan gambar penuh dengan sokongan kekunci anak panah & `Esc`.
- **Borang Janji Temu UBK Interaktif:** Borang permohonan bimbingan kaunseling digital secara langsung.

## 📑 Struktur Halaman

1. `index.html` — **Muka Utama** (Hero Showcase, Ticker Pengumuman, Statistik Interaktif, Perutusan Guru Besar, Pautan DELIMa & APDM).
2. `pentadbiran.html` — **Pentadbiran** (Visi, Misi, Piagam Pelanggan, Carta Organisasi Pengurusan, Direktori Guru & Kakitangan dengan Carian).
3. `kurikulum.html` — **Kurikulum** (Panitia Teras dengan Tab Interaktif, Pembelajaran PAK21/STEM, Jadual Waktu Persekolahan).
4. `kokurikulum.html` — **Kokurikulum** (Pengakap Kanak-Kanak, BSMM, Kelab Warisan Seni Asli, Sukan 1M1S, Dewan Kegemilangan).
5. `hem.html` — **Hal Ehwal Murid** (Skim Bantuan Kebajikan BAP/SPBT, Jadual Menu RMT Harian, Borang Janji Temu UBK, Program 3K).
6. `galeri.html` — **Galeri Aktiviti** (Penapis Foto Kategori Sukan, Akademik, Kebudayaan, Perkhemahan & Fullscreen Lightbox).

## 🚀 Cara Menjalankan Secara Tempatan

Laman web ini adalah **Zero Build Step** — tiada perisian tambahan diperlukan untuk melihatnya:

1. Klon repositori ini:
   ```bash
   git clone https://github.com/myrocreativestudio/sesmas.git
   cd sesmas
   ```
2. Buka fail `index.html` terus dalam mana-mana pelayar web moden (Chrome, Safari, Edge, Firefox), ATAU jalankan pelayan tempatan:
   ```bash
   # Menggunakan Python
   python3 -m http.server 8080

   # Atau menggunakan Node.js npx
   npx serve .
   ```
3. Akses laman web di: `http://localhost:8080`
